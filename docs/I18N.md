# Internationalization

## Languages and routing

Five languages, route prefix always present: `/pt/`, `/en/`, `/es/`, `/de/`, `/it/`. `/` is redirected at the edge from `Accept-Language` (first supported match, fallback `/en/`). The Worker never sees a visitor's language choice (no cookies). The LanguageSwitch script remembers the language picked with a plain click in the header links, and on a language home reached through the `/` redirect, `/prefs.js` replaces that home with the remembered language before it paints (ADR-0011, ADR-0012). Every page carries `hreflang` alternates and an `x-default` pointing to `/en/`. Slugs are shared across languages (`/pt/exhibits/ab-plc-5`, `/de/exhibits/ab-plc-5`); the exhibit name is not translated.

## What gets translated

- UI strings: `src/i18n/<lang>.json`, flat keys, human-verified in pt and en; es, de, it generated with the glossary and marked `"_status": "machine"` until a native reviews them.
- Exhibit text (`text.<lang>`): tagline, summary, field_quirk, alt_text. Generated by `/translate-exhibit` from the pt or en master using `content/glossary.json`. Each language block carries `status`.
- Stories: stored in the original language only. The build generates `translations.<lang>` for display behind a "Show translation (machine)" control. The original is always shown first.
- Never translated: product names, part numbers, protocol names, numbers and units (the specs block is language-neutral by design), contributor names.

## Glossary (`content/glossary.json`)

Term keys with per-language jargon used by engineers of each country, not dictionary translations. Examples: `plc` → pt "CLP (PLC)", es "PLC (autómata programable)", de "SPS", it "PLC"; `dcs` → pt "SDCD", de "PLS (Prozessleitsystem)"; `ladder` → de "KOP", `il` → de "AWL", `fbd` → de "FUP", `st` → de "SCL/ST", `scan_time` → de "Zykluszeit". The translation skill must pass the glossary in the prompt and must keep the German terms for STEP 5 era content (KOP/FUP/AWL were the originals; LAD/FBD/STL are the English renderings).

## "Help us review" badge

When a language block has `status: machine` or `needs_review`, the page shows a small badge: "Machine translation. Are you a native engineer? Help us review." linking to the contribute page with the exhibit id and language prefilled. This is the recruiting hook for German and Italian veteran curators.

## Formatting

Dates and numbers use `Intl` with the page language. Years in the stage watermark are digits only. Decade labels are localized (`anos 1980`, `1980s`, `años 80`, `1980er`, `anni '80`).

## Quality bar before publishing a language

pt and en: human-verified for every published exhibit. es, de, it: may ship as `machine` with the badge; the glossary must be respected (validator checks that glossary terms appear in the machine output where the master used them).
