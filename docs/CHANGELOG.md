# Changelog

Dated lines, newest first. One line per merged PR or content batch. No personal data.

- 2026-10-15: ADR-0010 accepted and implemented: Astro's `security.csp` hashes the inline island scripts and styles, the build lists them in `csp.json`, and the Worker adds them to `script-src` and `style-src` of its CSP (read once per isolate, documented policy as fallback), so React islands hydrate without `'unsafe-inline'`. The edge e2e tests check the header against `csp.json` and hydrate a test island with `client:load`, `client:idle` and `client:visible` under `wrangler dev` (test page built only with `PLCMUSEUM_E2E_FIXTURES=1`, as CI's e2e job does).
- 2026-10-15: D1 databases created for stories (production and preview) and their ids set in wrangler.jsonc; API token permissions documented as Cloudflare requires them for the first deploy and the custom domains.
- 2026-10-15: Phase 0 foundation: Astro 7 static site (ADR-0009, replacing Astro 5 over unfixed advisories) with TypeScript strict, Tailwind v4 on the design tokens and React islands; content collections with a Zod mirror of the schemas and generated types; museum theme tokens with contrast tests and five era theme skeletons; five-language routes, exhibit and decade pages, sitemap and per-language 404 pages; Cloudflare Worker with security headers on every response, Accept-Language redirect and /api/health; story, image and deploy script skeletons; validator checks for illustrations and SVG safety; unit and end-to-end tests including a CSP check in a real browser; CI on pnpm 10 pinned by packageManager; tighter Claude Code permissions. Tooling dependencies approved by the maintainer: @tailwindcss/vite, @astrojs/check, typescript, @eslint/js, typescript-eslint, eslint-plugin-astro, prettier-plugin-astro, @types/react, @types/react-dom. Proposed: ADR-0010 (CSP hashes for island hydration).
