# Changelog

Dated lines, newest first. One line per merged PR or content batch. No personal data.

- 2026-10-15: repeat page views no longer revalidate static files before first paint: the Worker sends `Cache-Control: private, max-age=31536000, immutable` on content-hashed files under `/_astro/`, and the build serves `/prefs.js` as `/_astro/prefs.<hash>.js` (HTML keeps revalidating). `/prefs.js` verified in Firefox and WebKit: WebKit counts the `/` redirect only in `performance.navigation`, so the remembered language is followed there too; opt-in Playwright projects `edge-firefox` and `edge-webkit` run over HTTPS.
- 2026-10-15: TASK-004 and TASK-005 contracts. TimelineScrubber is a native range input with one step per exhibit over a decade axis (`TimelineItem` is `id`, `yearLabel`, `name`, `decade` and `valueText`; the props are `items`, `listId`, `labels` and `onSelect`; the current exhibit is read from the stage list, where CoverFlow keeps `data-center-id`, and CoverFlow centers timeline picks without announcing them). Header controls without React (ADR-0011): `EraToggleProps` becomes `{ lang }`, `LanguageSwitchProps` is removed, and `ERA_HOOKS` (`data-page-era` on `<html>`, written by the layout from each page), `ERA_TOGGLE_HOOKS` and `LANGUAGE_HOOKS` are added. ADR-0012 accepted and implemented: `/prefs.js`, a classic script first in every `<head>`, applies the stored era and follows the remembered language before first paint (no CSP change, at most 1 KB gzip, with a parity unit test and edge tests). UI keys `timeline.label` and `timeline.value`, the Era style strings and a privacy note on remembered choices in the five dictionaries; every `tests/e2e/fixtures/*.astro` becomes an `/e2e/` test page in e2e builds; the focus ring is checked against the header background in the token tests; implementer captures are attached to PRs, never committed.
- 2026-10-15: long words wrap instead of running out of the column at 320 px with WCAG text spacing (German compounds, monospace eras); an e2e check covers every language and era.
- 2026-10-15: TASK-002 review rules for era themes, enforced by the token tests: stage geometry stays the museum's, no restated museum values, decoration behind the content, and accent, focus and text at least 10 CIEDE2000 from every state color; the decade bar keeps room for the focus ring at any border width.
- 2026-10-15: TASK-001 review decisions in the contracts: stage tokens `--stage-item-width`, `--stage-pitch` and `--stage-depth`; the stage link `a.card` gets an id and a name with the maker, and becomes the listbox option when CoverFlow is active (no control nested in an option); the initial center-change event and focus on external selection are specified; the year watermark span joins `STAGE_HOOKS`.
- 2026-10-15: first preview deploy, behind Cloudflare Access; wrangler.jsonc pins `workers_dev` and `preview_urls` to false so no workers.dev URL can bypass Access.
- 2026-10-15: ADR-0010 accepted and implemented: Astro's `security.csp` hashes the inline island scripts and styles, the build lists them in `csp.json`, and the Worker adds them to `script-src` and `style-src` of its CSP (read once per isolate, documented policy as fallback), so React islands hydrate without `'unsafe-inline'`. The edge e2e tests check the header against `csp.json` and hydrate a test island with `client:load`, `client:idle` and `client:visible` under `wrangler dev` (test page built only with `PLCMUSEUM_E2E_FIXTURES=1`, as CI's e2e job does).
- 2026-10-15: D1 databases created for stories (production and preview) and their ids set in wrangler.jsonc; API token permissions documented as Cloudflare requires them for the first deploy and the custom domains.
- 2026-10-15: Phase 0 foundation: Astro 7 static site (ADR-0009, replacing Astro 5 over unfixed advisories) with TypeScript strict, Tailwind v4 on the design tokens and React islands; content collections with a Zod mirror of the schemas and generated types; museum theme tokens with contrast tests and five era theme skeletons; five-language routes, exhibit and decade pages, sitemap and per-language 404 pages; Cloudflare Worker with security headers on every response, Accept-Language redirect and /api/health; story, image and deploy script skeletons; validator checks for illustrations and SVG safety; unit and end-to-end tests including a CSP check in a real browser; CI on pnpm 10 pinned by packageManager; tighter Claude Code permissions.
